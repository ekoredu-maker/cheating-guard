# 칫팅가드 (CheatingGuard) – 스마트 글라스·몰래카메라 탐지 보조 도구 v1.3.0

> 이전 이름: GlassGuard (v1.0.0~v1.1.0)

스마트폰의 카메라·플래시·블루투스·센서를 이용해 주변의 **카메라형 스마트 글라스 후보**와 **몰래카메라·소형 무선 카메라 후보**를 탐색하는 무료 PWA(Progressive Web App)입니다.
서버·회원가입·광고가 없으며, 모든 분석은 스마트폰 안에서만 이루어집니다.

- 배포 예정 주소: https://ekoredu-maker.github.io/cheating-guard/
- 저작권: 2026@박주가리 교감
- 라이선스: MIT (LICENSE 참고)

> 이 프로그램은 스마트 글라스 및 카메라 렌즈 후보를 탐색하는 보조 도구입니다. 스마트폰 기종과 브라우저에 따라 일부 기능이 제한될 수 있으며, 모든 스마트 글라스를 탐지할 수 있는 것은 아닙니다. 탐지 결과만으로 촬영 여부나 부정행위를 판단할 수 없습니다.

## 3. 미구현 및 미검증 기능 목록

**의도적으로 구현하지 않은 기능 (표준 PWA에서 불가능하거나 원칙상 금지)**
- **Wi-Fi 네트워크 목록 자동 스캔**과 공유기 내부 기기 검색 (브라우저 보안상 불가능 — 사용자가 Wi-Fi 이름을 직접 입력하는 방식으로 대체), 전파 세기(RF) 측정
- Wi-Fi 주변 기기 검색, Bluetooth Classic 직접 검색, ToF 원시 데이터, 열화상 탐지
- 주변 모든 BLE 기기의 자동 목록화(Web Bluetooth는 사용자가 선택한 기기만 허용, 실험 기능 제외)
- 정밀 위치(레이더 좌표) 추정, 탐지 확률(%) 표시 — 방향은 360° 회전 측정으로 대략적인 방위만 제공
- 얼굴 인식·개인 식별·사람 추적
- 대상 기기에 GATT 연결(타인 기기 접속을 피하기 위해 연결하지 않음)
- 백그라운드 탐지(브라우저가 허용하지 않음)

**미구현 (2차 기능)**
- 스마트 글라스 전용 AI 분류 모델: 검증된 학습 데이터·모델이 없어 탑재하지 않음 (모듈 구조만 준비)
- 촬영 표시등의 촬영 상태 확정 판정, QR 코드 공유

**미검증 (실기기 시험 미실시)**
- 모든 실기기(갤럭시·기타 안드로이드·아이폰) 동작, 실제 스마트 글라스 탐지율·오탐률·탐지 시간
- 데이터베이스 중 블루투스 수준 ‘U(미확인)’ 모델의 식별자, 모든 모델의 사양 출처 재확인
- 광고 패킷 지문 `META_RB_GLASS`(공개 문서 예시, 실측 미확인 — 낮은 가중치로만 사용)
- 홈 화면 설치 후 아이콘 표시, iOS Safari 동작
- 몰래카메라 기능 전체의 실제 카메라 대상 탐지 성능, 휴대폰 기종별 적외선 감지 여부
- Tuya BLE 서비스 UUID(문서 표기 0xA201)의 바이트 순서 해석, DGK- Wi-Fi 이름 규칙(출처 1건)

## 4. GitHub Pages 배포 (요약)

1. GitHub에 `ekoredu-maker` 계정으로 로그인 → 새 저장소 `cheating-guard`(Public) 생성
2. ZIP 압축을 푼 **안의 파일 전체**를 저장소 최상위에 업로드 (`index.html`이 최상위에 있어야 함)
3. Settings → Pages → Branch: `main` / `/ (root)` → Save
4. 1~3분 후 https://ekoredu-maker.github.io/cheating-guard/ 접속

자세한 절차와 확인 목록은 [DEPLOY.md](DEPLOY.md)를 참고하세요.
